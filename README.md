# 🐒 MonkeCraft Launcher

**MonkeCraft** — лаунчер для автоматической установки, обновления и запуска Minecraft с нашим модпаком.

Лаунчер самостоятельно загружает необходимые файлы игры и модификации, поддерживая актуальную версию сборки.

## 💻 Установка

### Installer

1. Скачайте установщик из раздела [Releases](https://github.com/s1derr1337/MonkeCraft-Launcher/releases/latest).
2. Запустите `MonkeCraft-Setup.exe`.
3. Выберите папку установки.
4. Завершите установку и запустите лаунчер.

### Portable

1. Скачайте Portable-архив из [Releases](https://github.com/s1derr1337/MonkeCraft-Launcher/releases/latest).
2. Распакуйте архив в удобное место.
3. Запустите `MonkeCraft.exe`.
